# Release Health Lab

## What The Product Does

A small containerized service with CI, logging, health checks, and AI-assisted incident analysis.

## Stack

- Docker
- GitHub Actions
- structured logging
- health checks
- Vercel and Railway deployment practice
- one tiny user-visible feature plus the release pipeline

## Why It Exists

This is the Month 5 project because it teaches:

- deployment discipline
- reading build failures
- diagnosing logs
- production readiness
