# Week 5 - Schema Design

## Expected Outcome

- Design a database schema for a new feature.
- Defend your primary keys, foreign keys, and indexes.
- Show the query plan for the most complex query.

## What To Show

- The schema diagram or SQL.
- Your reasoning for each table and index.
- The performance story behind the plan.

## Completion Check

- [ ] The schema supports the feature cleanly.
- [ ] The design avoids obvious bottlenecks.
- [ ] I can explain the tradeoffs.
