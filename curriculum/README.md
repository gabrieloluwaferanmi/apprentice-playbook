# ParallelScore Apprentice Playbook

This folder turns the 6-month playbook into a navigable curriculum.

## Curriculum Goal

The playbook starts with small, bounded projects and grows into a full capstone in Month 6.

Each month introduces only one or two new ideas at a time so learners can build confidence while moving toward the full stack:

- JavaScript and terminal fluency
- Next.js
- NestJS
- PostgreSQL
- MongoDB
- Redis
- API integrations
- notifications
- deployment
- AI-assisted workflows

## How To Use

1. Start with the month overview.
2. Open the matching week folder.
3. Open the month-local project spec and product README.
4. Work inside the matching project folder for that month.
5. Complete the week deliverable and demo it on Friday.

## Recurring Rituals

- Wednesday: open PR walkthrough with a senior engineer.
- Friday: working demo and explanation of what broke.
- Every two weeks: bug hunt against subtle AI-generated defects.
- Midpoint: a human check-in, not a performance review.
