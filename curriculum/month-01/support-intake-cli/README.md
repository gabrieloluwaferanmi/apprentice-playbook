# Support Triage CLI

## What The Product Does

A command-line tool that captures one support issue, uses AI to summarize it, and writes a structured intake record for the team.

## Stack

- JavaScript
- Node.js
- file-based storage
- AI text generation API

## Why It Exists

This is the Month 1 project because it teaches:

- terminal fluency
- local debugging
- rule-driven AI prompting
- how to turn messy human input into a useful product artifact
- how to keep the scope tiny while still shipping something useful
