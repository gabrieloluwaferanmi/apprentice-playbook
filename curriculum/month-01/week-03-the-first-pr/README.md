# Week 3 - The First PR

## Expected Outcome

- Ship a small bug fix on an existing tool.
- Walk through the PR line by line.
- Explain the code you did not write.

## What To Show

- The bug fix itself.
- Notes from the Wednesday review.
- The decisions you made while merging.

## Completion Check

- [ ] The PR is small and readable.
- [ ] I can defend the changes.
- [ ] I captured the review notes.
