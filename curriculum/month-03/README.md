# Month 3 - Frontend Resilience & Accessible UI

## Objective

Build UIs that humans actually want to use, and that all humans can use.

## Concepts Introduced

- Next.js page composition
- responsive UI behavior
- accessible state and error handling

## Tech Skills, Tools, and Knowledge

- Skills: Next.js composition, responsive layout work, state management, accessibility checks
- Tools: Next.js, React, Zustand, browser devtools, screen reader testing, CSS or Tailwind
- Knowledge: component lifecycle, rendering behavior, ARIA, keyboard navigation, error states

## What This Month Trains

- React mental model and component lifecycle
- Context plus Zustand for state
- Browser rendering and performance
- Semantic HTML, ARIA, keyboard navigation, and screen reader testing
