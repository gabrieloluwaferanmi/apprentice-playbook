# Notification Delivery Router

## What The Product Does

A NestJS service that routes event-based notifications through email, SMS, or push based on user preferences and event type.

## Stack

- NestJS
- PostgreSQL
- Redis
- email provider integration
- SMS provider integration
- push provider integration
- one primary event stream
- one delivery log

## Why It Exists

This is the Month 4 project because it teaches:

- authentication and authorization
- secret handling
- channel selection
- queued outbound delivery
