# Month 4 - Security, Identity & Secrets

## Objective

Become an excellent guardian of user data.

## Concepts Introduced

- authentication and authorization
- secrets management
- notification delivery routing

## Tech Skills, Tools, and Knowledge

- Skills: auth guard design, secret handling, delivery routing, safe input handling
- Tools: NestJS, JWT or sessions, environment variables, email/SMS/push provider SDKs
- Knowledge: OAuth basics, CORS, SQL injection, secrets management, prompt injection risks

## What This Month Trains

- OAuth, JWTs, session management, and token storage
- CORS, SQL injection prevention, and the OWASP Top 10
- Secrets management and runtime injection
- Prompt injection awareness for AI-facing features
