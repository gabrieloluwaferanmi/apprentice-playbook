# apprentice-playbook

This repo is the learner-facing home for the ParallelScore Apprentice Playbook.

## What This Repo Is For

The goal is to take an apprentice from JavaScript fundamentals to building and shipping real products with:

- Next.js
- NestJS
- PostgreSQL
- MongoDB
- Redis
- API integrations
- notifications
- Vercel and Railway deployments
- safe AI-assisted workflows

## How To Use This Repo

1. Start on `main`.
2. Create your own branch from `main` for the month or task you are working on.
3. Open [`curriculum/README.md`](./curriculum/README.md).
4. Follow the month overview, then open the matching week folder.
5. Work in the month-local project folder and read its `spec.md` before building.
6. Demo the result on Friday and keep your work small enough to review.

## Repo Rules

- `main` is the shared baseline for all learners.
- Each learner should branch from `main` before starting work.
- Each month has one project and one product spec.
- Month 6 is the only capstone month.

Curriculum details live in [`curriculum/README.md`](./curriculum/README.md).
